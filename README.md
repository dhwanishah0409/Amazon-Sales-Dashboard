# Amazon-Sales-Dashboard
Amazon sales analysis dashboard built using Microsoft Power BI.
Amazon Sales Dashboard

Project Overview

An interactive sales dashboard created using Microsoft Power BI to visualize sales performance, profitability, order distribution, and customer segments.

Dashboard Features

* Key Performance Indicators: Total orders, sales, and profit
* Shipping Analysis: Orders by shipping mode
* Customer Analysis: Consumer, Corporate, and Home Office segments
* Payment Analysis: Cash on Delivery, Online, and Card payments
* Sales Trends: Monthly sales and profit distribution
* Product Analysis: Top five profitable sub-categories
* Category Analysis: Sales across Office Supplies, Technology, and Furniture
* Regional Filtering: Central, East, South, and West

Key Metrics

* Total Orders: 5.901K
* Total Sales: 1.57M
* Total Profit: 175.26K

Tools Used

* Microsoft Power BI
* Data Visualization
* Business Intelligence
